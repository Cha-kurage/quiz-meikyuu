# Quiz迷宮 (quiz-meikyuu)

謎解き公演「Quiz迷宮」のWebサイト実装リポジトリ。

## 概要

天狗が案内役を務める早押しクイズ形式の謎解きサイト。プレイヤーは15問のクイズに答え、
解答ゾーンにパーツを配置して単語を組み立てながら最終謎の解答を目指す。

仕様の元スライド: Google スライド (非公開。リンクは制作メンバーに確認)

## ディレクトリ構成

```
.
├── index.html          # エントリーポイント
├── assets/
│   ├── images/
│   │   ├── parts/       # 解答用パーツ (文字・イラスト、ファイル名は ASCII)
│   │   ├── ui/          # 石板など UI 用画像
│   │   └── decor/       # 松明などの装飾
│   ├── icons/            # ボタン・アイコン素材
│   └── sounds/           # BGM・効果音
├── src/
│   ├── css/style.css
│   └── js/
│       ├── parts.js     # パーツ置き場の初期配置データ
│       ├── main.js      # ステージ拡縮・パーツ描画
│       ├── drag.js      # パーツのドラッグ移動 (解答ゾーンに置く/石板に戻る) + ダブルクリック回転
│       ├── questions.js # 問題データ (問題文・答え、全15問のうち14問分)
│       ├── quiz.js      # 出題フロー・早押しボタン (一時停止/再開)・戻る/進むでの問題切り替え
│       ├── answers.js   # 正誤判定 (パーツ間の相対座標を許容誤差つきで判定。ANSWER_CHECKS に問題ごとの配置ルールを書く)
│       └── debug-coords.js # 開発用: 解答ゾーン内のパーツ座標・回転角を調べるパネル
├── パーツ類/            # 元素材 (Illustrator / 元PNG)
└── README.md
```

## ローカルでの確認

プロジェクト直下で簡易サーバーを立てて http://localhost:8000 を開く。

```bash
python3 -m http.server 8000
```

画面は 1600x900 の固定ステージを画面サイズに合わせて拡縮している（PC と スマホ横向き想定）。

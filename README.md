# Quiz迷宮 (quiz-meikyuu)

謎解き公演「Quiz迷宮」のWebサイト実装リポジトリ。

## 概要

天狗が案内役を務める早押しクイズ形式の謎解きサイト。プレイヤーは15問のクイズに答え、
解答ゾーンにパーツを配置して単語を組み立てながら最終謎の解答を目指す。

仕様の元スライド: [Google Slides](https://docs.google.com/presentation/d/1nuHOdW2vCmclLUcJfhsuU5tnRIgITwCy/edit)

## ディレクトリ構成

```
.
├── index.html          # エントリーポイント
├── assets/
│   ├── images/          # 背景・イラスト・答えパーツ画像
│   ├── icons/            # ボタン・アイコン素材
│   └── sounds/           # BGM・効果音
├── src/
│   ├── css/
│   └── js/
└── README.md
```

## 素材の出典・ライセンス

使用する外部素材（効果音・イラスト・アイコン）は `assets/CREDITS.md` に出典とライセンス条件をまとめる。
